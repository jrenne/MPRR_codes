# Companion code for *Asset Pricing with Discrete-Time Affine Processes*

This repository contains the Bookdown companion to the book by Jean-Paul
Renne, Alain Monfort, Fulvio Pegoraro, and Guillaume Roussellet. It provides R
code for reproducing the book's figures, tables, simulations, and numerical
illustrations.

The rendered companion website is available at:

<https://jrenne.github.io/MPRR_codes/>

Most examples use the open-source R package DTAM:

<https://github.com/jrenne/DTAM>
